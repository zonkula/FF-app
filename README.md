# FF-app

A 1v1 fantasy football weekly draft app with PPR (points-per-reception) scoring.

## Overview

Two players draft a lineup of NFL players each week and compete head-to-head based on PPR fantasy scoring for that week's real-world stats.

## Stack

- React 18 + TypeScript
- Vite
- Tailwind CSS

## Project structure

```
src/
  components/   # React components
  utils/        # Scoring logic and other helpers
public/         # Static assets
```

## Getting started

```bash
npm install
npm run dev
```

Copy `.env.example` to `.env` and fill in any required values before running.
